# XXD Panel 354｜粗墨涂鸦

上半保留原照，下半把主体和最能说明它在做什么的几样小道具画成圆胖稚拙的正面简笔形：每样东西都被一圈粗而微微抖动的黑色墨线圈住，线里只平涂一块颜色，一起站在一条横贯画面的粗黑地面线上，背后是一整片奶油色空底；旁边用同样的粗墨线手写一句小话，像漫画格里随手冒出来的。

## 适用场景与解决的问题

适合想把一张日常照片变成一页憨厚、好笑的绘本小格的时候：遛狗的人、晾衣绳、一袋刚买的菜、揉面的手、窗边的猫、一只呆呆的鹅。也适合构图差、背景乱、主体小的照片——下半会删掉环境和透视、把主体转成正面、放上那条地面线，再配一两样说明它在做什么的小道具，把它救成一格安静又好笑的日常。照片本身是场景时，只取最有代表性的一个单体或片段。

关键是每样东西都被一圈粗而微抖、线头圆钝的黑色墨线圈住，线里只平涂一块颜色、偶尔没对准线；外形圆胖略歪，毛发和枝叶只把外轮廓画成一串小圆鼓包，脸上只有两颗小黑点眼睛和一个小鼻头或一笔短嘴；所有东西落在一条从左画到右的粗黑地面线上，上方留出大片奶油色空白；主体用照片里最有存在感的颜色并略降饱和，只有一处小亮色点睛；旁边一句同样粗墨线的圆胖手写小话。避免完整场景复刻、背景填满、细而均匀的矢量线、没有墨线圈住的色块、东西飘在空中、写实比例、过细的五官、堆满的道具和光滑的吉祥物卡通。

## 使用窍门

- **先给一张清楚的照片：** 先选一张主体、动作和关系都容易辨认的图，再决定输出方式与比例。
- **一句话串起参数：** 直接说“上下对照 / 左右对照 / 纯设计 + 16:9 / 3:4 / 手机壁纸”，也可以补充电脑、平板或电子手表尺寸。
- **把必须保留的内容说清楚：** 指定人物、物件、动作、关系和文字；避免同时规定过多布局细节，让风格有空间完成设计。
- **文字有三种选择：** 让模型按图片智能生成、用 `--text exact --copy` 锁定逐字文案，或用 `--text none` 完全不要文字。
- **说明现实区与设计区：** 上下或左右对照时，注明哪一侧保留照片、哪一侧负责设计转译；纯设计和壁纸则说明整张画布都要重新设计。
- **先单张试，再批量做：** 先用一张图确认模式、比例、文字和语言，再把同一套参数用于目录批处理；每轮只改一个变量，结果更容易比较。

## 开始使用

从 GitHub 安装：

```bash
npx skills add https://github.com/nevertoday/xxd-panel-354 --skill xxd-panel-354
```

安装后重新启动 Agent 会话，然后调用 `$xxd-panel-354`。也可以按需追加 `--global --agent codex --yes` 做用户级安装。

常用调用示例：

```text
/xxd-panel-354 photo.jpg --mode top-bottom --size 3:4 --text prompt --locale zh-CN
/xxd-panel-354 photo.jpg --mode left-right --size 16:9 --text prompt --locale en-US
/xxd-panel-354 photo.jpg --mode design-only --size 9:16 --text none --prefs off
/xxd-panel-354 ./photos --mode design-only --size auto,3:4 --text prompt --locale ja-JP
```

完整运行契约见 [SKILL.md](SKILL.md)；运行适配器见 [英文](references/xxd-panel-354-prompt.en.md) 与 [中文](references/xxd-panel-354-prompt.zh-CN.md)。

## 快速判断：Panel 354 适合你吗？

既要保留源图身份，也要重新构图；既要材质特征，也要主动留白。可选准确文字、智能文案或无文字；支持单图、递归目录批量以及下方四种交付模式。

## 四种输出模式

- `top-bottom`：整张画布只有上下两个全宽区域，现实照片在上、设计在下，严格各占 50%。
- `left-right`：整张画布只有左右两个全高区域，现实照片在左、设计在右，严格各占 50%，不会旋转成上下结构。
- `design-only`：整张画布只呈现 Panel 354 的设计转译，照片只作为不可见参考。
- `wallpaper-pack`：按手机、iPad、桌面和手表分别生成完整设计壁纸，可选 `linked` 连贯套装或 `independent` 四张独立。

支持多选模式与比例（`1:1`、`3:4`、`4:3`、`4:5`、`5:4`、`2:3`、`3:2`、`9:16`、`16:9`、`21:9`、`5:7`、`7:5` 或准确像素），以及模型生成文字、准确文字和无文字。传入目录会递归扫描图片，每张源图独立处理，共用一次交付设置；最终 PNG 平铺放入一个新任务目录。
